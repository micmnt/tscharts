## Usage

```ts
import { GroupBar, Chart } from "tscharts";

const Example = () => {
  return (
    <Chart>
      <GroupBar name="serie1" />
    </Chart>
  );
};

export default Example;
```

#### Arguments

- **name** - A string that represents the serie (group) associated with the bars
- **stacked** - Optional. `Default value: false`. A boolean that determines if the bars in each group are stacked.
- **showLabels** - Optional. `Default value: false`. A boolean that determines if show or hide the bars' value labels.
- **topLabelSerie** - Optional. The name of a serie whose values are shown as labels above each group.
